# Google Stitch Design-to-Code Workflow

When working with Google Stitch designs:
1. **Design Extraction**: Use Stitch MCP tools to retrieve design metadata, screens, and design tokens (Design DNA: color palette, typography, layout).
2. **Component Integration**: Translate retrieved HTML/CSS screens into clean, modular Vue/React/Web components adhering to the project's design system.
3. **Asset Handling**: Fetch screen images and assets directly through Stitch MCP tools rather than requesting manual exports.
